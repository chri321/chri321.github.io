虚拟机网络配置详解

2024-12-24

虚拟机常见的三种网络配置方式：桥接模式（Bridged）、NAT 模式、仅主机模式（Host-Only）。

三种网络模式对比

模式说明特点
桥接模式（Bridged）虚拟机表现得像物理网络上的独立设备，拥有自己的网络接口，参与 ARP 请求和广播流量直接连接物理网络，可与同网络其他设备通信
NAT 模式虚拟机通过宿主机的网络接口访问外部网络，流量被宿主机网络堆栈转换并转发虚拟机 IP 对外部不可见，通过宿主机 IP 通信，通常使用端口转发
仅主机模式（Host-Only）虚拟机只能与宿主机通信，不能直接访问外部网络连接到虚拟私有网络，不与任何物理网络接口相连，适合隔离测试环境

NAT（网络地址转换）

全称 Network Address Translation，主要用于缓解 IPv4 地址短缺。有了 NAT 之后，可以令多个网络设备共享一个公网 IP 地址，家庭路由器中也集成了该服务。

桥接模式

VMware 虚拟出一个交换机、一个 DHCP 服务以及一个 NAT 服务，相当于构成了一个虚拟路由器。

在虚拟机上使用主机的 VPN

NAT 模式下，虚拟机通过主机的网络接口访问网络。可以在虚拟机上设置代理，让所有流量通过主机的 VPN 端口。

步骤：

  1. 查看主机 VPN 端口：查看主机上 VPN 应用使用的端口号，通常在 VPN 应用设置中可以找到。
  2. 查看虚拟机网络 IP：获取虚拟机的 IP 地址，可通过虚拟机操作系统中的网络设置查看，或在主机的虚拟机管理软件中查看。
  3. 在虚拟机上配置代理：在虚拟机中设置网络代理，使其通过主机的 VPN 端口进行网络通信。
