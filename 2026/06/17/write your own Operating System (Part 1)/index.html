write your own Operating System (Part 1)

2026-06-17

传统 BIOS + MBR 架构 下 Linux 系统完整开机启动链路，从主板硬件上电到系统初始化全流程如下：

主板核心硬件

  • CPU — 处理器
  • RAM — 内存，临时存放运行数据
  • HD — 硬盘，永久存储操作系统与用户数据
  • BIOS（Flash ROM 固件） — 上电后首次执行的程序，完成：
    1. 开机自检（POST）
    2. 硬件初始化
    3. 根据启动顺序寻找可引导盘

MBR 分区启动阶段

1. MBR（主引导记录，Master Boot Record）

硬盘最开始的 512 字节 区域，分为三个部分：

大小内容
446 字节Bootloader 引导程序
64 字节分区表，记录硬盘分区信息
2 字节启动校验标识（0x55AA）

2. 引导流程

BIOS 读取硬盘 MBR 后，将控制权交给 MBR 中的引导程序。引导程序随后加载 /boot 分区中的 Linux 内核，并将控制权移交给内核，由内核继续完成系统初始化。
