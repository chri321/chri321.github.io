常用 Docker 命令

命令说明
docker ps查看运行中的容器
docker images查看镜像列表
docker rm <container-id>删除指定容器
docker stop/start <container-id>停止/启动容器
docker rmi <image-id>删除指定镜像
docker volume ls查看卷列表
docker network ls查看网络列表
